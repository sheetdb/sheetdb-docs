## Getting started {{ anchor: false }}

To get started, create a new API in your <TrackedLink href="https://sheetdb.io/app/apis">dashboard</TrackedLink>, then make sure your spreadsheet is in the correct format - column names should be in the first row. After creating the API, you will receive a unique ID.
